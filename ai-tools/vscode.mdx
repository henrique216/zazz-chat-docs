---
title: "VS Code"
description: "Conecte a documentação do Zazz Chat ao VS Code pelo servidor MCP"
---

Crie o arquivo `.vscode/mcp.json` no projeto:

```json .vscode/mcp.json
{
  "servers": {
    "zazz-chat-docs": {
      "type": "http",
      "url": "https://docs.zazzinternet.com/mcp"
    }
  }
}
```

Ou instale pelo menu **Copiar página**, ao lado do título de qualquer página desta doc.
