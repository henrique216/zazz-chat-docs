## Servidor MCP

Abra a paleta de comandos, rode **Open MCP settings** e clique em **Add custom MCP**. No `mcp.json`, adicione:

```json mcp.json
{
  "mcpServers": {
    "zazz-chat-docs": {
      "url": "https://docs.zazzinternet.com/mcp"
    }
  }
}
```

Ou instale pelo menu **Copiar página**, ao lado do título de qualquer página desta doc.

## Skill

No projeto onde você vai integrar:

```bash
npx skills add https://docs.zazzinternet.com
```
