---
title: "Capturar atendimento"
api: "POST /channel-api/chats/{id}/capture"
description: "Um usuário assume a conversa que está na fila"
authMethod: "none"
---

<ParamField header="Authorization" type="string" required>
  API key de conta no formato `ApiKey <token>`. Scope exigido: `chats:capture`. Veja [API key de conta](/guias/introducao#api-key-de-conta).
</ParamField>

<ParamField path="id" type="string" required>
  ID da conversa. Conversa inexistente ou de canal fora da key retorna `404`.
</ParamField>

<ParamField body="userId" type="string" required>
  Usuário que assume o atendimento. Usuário inexistente ou cancelado retorna `400`.
</ParamField>

<Warning>
  A captura é recusada com `400` se a conversa já está `Em Atendimento`: ela nunca tira a conversa de outro atendente. Para reatribuir, use [Transferir conversa](/api-reference/endpoint/transferir-conversa). Se duas capturas chegam juntas, só a primeira vale e a segunda recebe `409`.
</Warning>

## Resposta

Conversa após a captura.

<ResponseField name="id" type="string">
  ID da conversa.
</ResponseField>

<ResponseField name="status" type="string">
  `open`.
</ResponseField>

<ResponseField name="queue" type="string">
  `Em Atendimento`.
</ResponseField>

<ResponseField name="channelId" type="string | null">
  Canal da conversa.
</ResponseField>

<ResponseField name="teamId" type="string | null">
  Equipe da conversa.
</ResponseField>

<ResponseField name="userId" type="string">
  Usuário que capturou.
</ResponseField>

<ResponseField name="contact" type="object | null">
  `id` do contato. `name` e `value` vêm `null` nesta resposta.
</ResponseField>

<ResponseField name="unreadMessages" type="integer">
  Mensagens não lidas.
</ResponseField>

<ResponseField name="lastMessage" type="object | null">
  Resumo da última mensagem: `origin` e `content` (`type`, `value`).
</ResponseField>

<ResponseField name="createdAt" type="string">
  Criação, ISO 8601.
</ResponseField>

<ResponseField name="updatedAt" type="string">
  Última atualização, ISO 8601.
</ResponseField>

<RequestExample>

```bash cURL
curl -X POST "https://chat.zazzinternet.com/channel-api/chats/66f2a1c9e4b0a1b2c3d4e5f6/capture" \
  -H "Authorization: ApiKey zk_live_SEU_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{ "userId": "66f1f0c2e4b0a1b2c3d4e200" }'
```

</RequestExample>
