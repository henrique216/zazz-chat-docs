---
title: "Listar equipes"
api: "GET /channel-api/teams"
description: "Lista as equipes, para escolher o destino de uma transferência"
authMethod: "none"
---

<ParamField header="Authorization" type="string" required>
  API key de conta no formato `ApiKey <token>`. Scope exigido: `teams:read`. Veja [API key de conta](/api-reference/introduction#api-key-de-conta).
</ParamField>

## Resposta

Array de equipes. Use o `id` como `teamId` em [Transferir conversa](/api-reference/endpoint/transferir-conversa).

<ResponseField name="id" type="string">
  ID da equipe.
</ResponseField>

<ResponseField name="name" type="string">
  Nome da equipe.
</ResponseField>

<ResponseField name="description" type="string | null">
  Descrição da equipe.
</ResponseField>

<ResponseField name="status" type="string">
  Status da equipe.
</ResponseField>

<ResponseField name="members" type="string[]">
  IDs dos usuários da equipe.
</ResponseField>

<RequestExample>

```bash cURL
curl "https://chat.zazzinternet.com/channel-api/teams" \
  -H "Authorization: ApiKey zk_live_SEU_TOKEN"
```

</RequestExample>

<ResponseExample>

```json 200
[
  {
    "id": "66f1f0c2e4b0a1b2c3d4e100",
    "name": "Suporte",
    "description": null,
    "status": "active",
    "members": ["66f1f0c2e4b0a1b2c3d4e200", "66f1f0c2e4b0a1b2c3d4e201"]
  }
]
```

```json 404
{
  "statusCode": 404,
  "message": "Not Found"
}
```

</ResponseExample>
