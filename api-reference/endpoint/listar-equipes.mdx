---
title: "Listar equipes"
openapi: "GET /channel-api/teams"
---

Exige uma [API key de conta](/api-reference/introduction#api-key-de-conta) com o scope `teams:read`.

Use o `id` da equipe como `teamId` em [Transferir conversa](/api-reference/endpoint/transferir-conversa). `members` traz os IDs dos usuários da equipe.
